# Телеграм-бот: Погода

Telegram бот, сам определит ваш город и отправит текущуюю погоду в нем.

## Установка
Чтобы запустить бота, необходимо выполнить следующие действия:

1. Клонируйте репозиторий и переключитесь в директорию с проектом
2. Введите команду:
```bash
chmod +x start.sh
```
3. Для запуска бота введите команду:
```bash
./start.sh
```
